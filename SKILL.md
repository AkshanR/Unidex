# ⚡ Unidex University & Course Extractor Skill

Use this skill when you need to research and add any university, college, course, or postgraduate program into **Unidex** (the fast, customizable college & course comparison tracker).

---

## 🎯 What This Skill Does
When given a university name, prospectus, brochure, or URL, the AI will:
1. Search and crawl the official university website.
2. Extract the exact fee structure (semester-by-semester, annual, and 2-year/full duration totals for Indian and International students).
3. Extract registration charges, application fees, and refundable security deposits.
4. Extract minimum eligibility criteria (percentage cutoffs, required graduation degree, 10+2 subject prerequisites like Mathematics/CS).
5. Extract application dates, intake sessions, and deadlines.
6. Enumerate **all specialized tracks / branches** with their individual fee variations, industry collaborations (e.g. Paytm, HCLTech, AWS), and core curriculum domains.
7. Output pure, validated JSON matching the Unidex schema below so the user can import it in 1 second.

## 📥 How to Import into Unidex
1. Copy the JSON output generated by the AI.
2. In the Unidex web app, click **"Import JSON"** in the top header.
3. Paste the JSON into the box (or select a `.json` file).
4. Click **"Import to Unidex"**.
5. The university and all its specializations will instantly appear in the **Notes View**, **Compare Table**, and **Specializations Matrix**!
